#Formulário de Inscrição Para Concurso

##Projeto desenvolvido em Python

Este programa simula uma inscrição para um concurso público.

## Funcionalidades

- Cadastro de Candidatos;
- Validação de Idade;
- Escolha da Escolaridade;
- Escolha da aréa Profissional;
- Uso de comandos adicionais;

## Tecnologias utilizadas 
- Python;
- VS code;
- Git;
- Git Hub;
